新建素材

删除本地文章

删除 = 移入回收站，文件不会立刻消失，可随时还原。
只影响本机素材库 / 生成产物 / 台账，不会删除公众号后台的草稿或已发布文章。

回收站 本地删除的文章

还原会把文件放回原来的位置；「彻底删除」才是永久抹掉，且不可恢复。

上传到公众号素材库

会把勾选的本地图片真实上传到公众号官方素材库（可在后台删除）。
成功后自动把 meta.json 里的本地路径换成微信 CDN 地址，并重新生成预览/排版片段；粘贴进编辑器时图片就能直接显示。
需要探针在线且已登录；不会点发表、不会群发。

补齐正文图片与封面

走公众号编辑器官方 UI，把已上传的图片插进草稿正文、设置封面，然后保存草稿。
不改正文文字、不点发表/群发；已存在的图片和封面会自动跳过，可重复执行。
需要探针在线且已登录公众号后台；「存草稿」按钮现在也会自动做这一步。

更新已存草稿

用本地最新内容覆盖公众号后台那篇【已有草稿】，appmsgid 不变、不会新建草稿。
会重写标题 / 作者 / 摘要 / 正文纯文本，并按本地图片清单重插正文图，保存后自动刷新复核。
不点发表 / 群发；后台手工改过的内容会被本地覆盖，完整排版仍需「复制排版」人工粘贴。
点「覆盖更新草稿」即执行：不新建草稿、不点发表/群发；只存草稿模式不变。
